# Football site — conceito em quatro cenas

Experiência estática, sem banco ou login, para publicação na Vercel. Os quatro vídeos fornecidos foram otimizados para reprodução web (H.264, sem faixa de áudio para autoplay silencioso); os originais não foram alterados. Os textos e a marca são provisórios até a revisão do roteiro.

Abra `index.html` por um servidor local, por exemplo `python3 -m http.server 4173`, e acesse `http://localhost:4173`. Na Vercel, importe este repositório como projeto **Other**, com diretório de saída `.` e sem comando de build.

Cada bloco da página inicia o seu vídeo quando entra em foco no scroll. A apresentação no celular preserva a proporção 16:9 dentro de uma área escura para não cortar a bola e a chuteira. Usuários que preferem menos movimento veem os posters estáticos.
