# Football site — conceito em quatro cenas

Experiência estática, sem banco ou login, para publicação na Vercel. Os quatro vídeos fornecidos foram preparados em 1280×720, H.264 com quadros independentes para busca rápida; os originais não foram alterados. Os textos e a marca são provisórios até a revisão do roteiro.

Abra `index.html` por um servidor local, por exemplo `python3 -m http.server 4173`, e acesse `http://localhost:4173`. Na Vercel, importe este repositório como projeto **Other**, com diretório de saída `.` e sem comando de build.

Cada cena ocupa uma tela de rolagem. O vídeo fica pausado e o scroll controla diretamente seu quadro, inclusive ao voltar para cima. O texto é compacto e permanece sobreposto; no celular, a imagem preserva a proporção 16:9 para não cortar a bola e a chuteira. Usuários que preferem menos movimento veem os posters estáticos.
